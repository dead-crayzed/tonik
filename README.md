
# Tonik

**Tonik** is a student-built music streaming platform focused on a simple and enjoyable listening experience.

> Project status: Planning & Initial Development

## About

Tonik is a collaborative educational project developed by a team of four students.

Our goal is to build a functional MVP of a music platform while gaining practical experience in software engineering, teamwork and Git-based development.

## Planned MVP Features

- Music catalog
- Audio player
- Track and artist search
- User accounts
- Personal playlists

Features may change during requirements planning.
